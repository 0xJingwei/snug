# 自用桌面屏分支

本仓库的 `feat/desktop-screen` 是自用版本。官方源为 `zephyr4123/snug`（`upstream`），自用远端为 `0xJingwei/snug`（`origin`）。本轮基于官方 2.4.4、提交 `16fe980` 合并，保留完整上游历史。

## 使用

- 手机、平板继续使用官方手机屏功能。
- 电脑通过 UU 远程连入时，新增「Snug 桌面屏」。在 UU 里选中它后，多块屏幕上的窗口聚拢到这块横屏；断开后按账本归位。
- 设置里的「还原窗口」会保持还原状态。再次切离并切回桌面屏，才重新聚拢。
- 创建、撤除桌面屏时保存并核对实体屏的模式。远程期间按本次登录恢复；远程结束、虚拟屏真正下线且实体屏醒着后，再补写当前永久配置。
- 已关闭启动时自动检查更新。设置里的手动检查仍指向官方包；更新自用版本请通过本分支构建安装，保留桌面屏功能。

## 跟进官方更新

从干净的 `feat/desktop-screen` 分支开始，先保留当前可用安装再执行：

```sh
git fetch upstream
git merge --no-ff upstream/main
./scripts/snug check
./scripts/snug app
```

有冲突时逐项兼容，重点检查 `AppController` 的手机屏与桌面屏调度、`LaunchMode` / `ModeTarget` 帮手参数、窗口恢复接口及显示模式保护。不要直接用官方文件覆盖定制部分，也不要强推或改写历史。

验收构建包的版本、签名、辅助功能权限和实体显示器模式后，替换 `/Applications/Snug.app`，再推送：

```sh
git push origin feat/desktop-screen
```

官方 `main` 与自用分支分别维护。没有自动后台更新或定时巡检；每次维护时检查上游，再合并、验证和安装。

## 签名和回滚

签名证书由本机未入库配置指定，不包含在仓库。当前用 Apple Development 证书签名，供本机使用，未经公证。持续使用同一包标识和证书，并以实际权限检查为准；不要重置已正常工作的辅助功能权限。

保留上一份正式 App 到安装验收结束；失败时先正常退出新进程，再还原旧包。真实远控的连接、UU 切屏、窗口聚拢和断开归位应另行核验，单元测试和加撤屏测试不能代替完整远控验收。

不要对本自用仓库运行 `scripts/snug ship`、`dist` 或 `mirror`；这些入口仍包含官方发行目标和公证配置。
