2026-11-15 主人提：一个视频里同时出现 Mac、外接显示器和 iPhone，手机上操作的同时让人看到屏幕怎么变化（原话「三块在一个视频中演示效果最炸裂」）。还有别的小需求要先做，这件暂缓，回来做时从这里接着。

**已定的方案**：全在这台 Mac 上用 OBS 采三块屏，内建屏（3024×1964）、外接 4K 屏、「Snug 手机屏」这块虚拟屏，不用第二台设备、不接线。

- **为什么**：手机上看到的就是 Snug 手机屏（UU 只是把它推过去），直接采原画是 1080×1900，比在手机上录还清楚；三路在同一个软件里采，点下去的那一帧三块屏一起变，不用后期对齐
- **触摸点**：UU 每次点击先把鼠标移到点的位置（见 [[project-phone-screen]] 的 UU 事件形态），手机屏那一路开「显示光标」就看得出点在哪。嫌箭头在手机上违和，可以打一个只给录屏用的本地版，在手机屏上画点击波纹，不进正式版（待主人选）
- **代价**：画面里没有 UU 的底栏、没有真手，后期给手机那一路套 iPhone 外框
- **排版**：三联画，手机居中当主角，左右各一块 Mac 屏
- **演示动作挑 Mac 实体屏上看得出变化的**：把外接屏上的窗口放上手机（从大屏消失、出现在手机上）、点「还原」让它飞回原处、在手机上退出 App 或关窗口。打字、新建窗口只在手机屏那块虚拟屏上变，实体屏上看不出来

**否掉的**：

- 另一部手机或摄像头俯拍手和手机：主人嫌麻烦，不用第二台设备
- iPhone 自带录屏：录不到手指，还要后期手动对齐，丢了「同时」
- 数据线接 iPhone、用 QuickTime 采手机画面：没有触摸点，还多一段延迟

**开干时**：先问一句用途。[[feedback-promo-video]] 里定过 kineto 宣传片以代码画为主、实机演示被否过，这次是实录，多半用在 README 演示或当宣传片的配角素材。然后装 OBS（`brew install --cask obs`，普通应用，第一次要在系统设置里给屏幕录制权限，装前等主人点头），配三联画场景，先录 30 秒验两件事：边给 UU 推流边录 4K + 3K 会不会让手机卡；光标在采集画面里清不清楚。

**How to apply:** 主人说回来做演示录制时读这里，照上面的方案直接推进，不再从头讨论；方案有变就改这份。
